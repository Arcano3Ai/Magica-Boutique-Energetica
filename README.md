## 🚀 Despliegue en GitHub Pages
Para publicar la tienda directamente en la web:
1. Dirígete a la pestaña **Settings** del repositorio en GitHub.
2. En la sección **Pages** (menú izquierdo), selecciona la rama `main` y la carpeta `/ (root)`.
3. Haz clic en **Save** y la tienda quedará activa en:  
   `https://arcano3ai.github.io/Magica-Boutique-Energetica/`
